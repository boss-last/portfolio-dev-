# 🎯 KPI Definitions

| KPI                         | Definition                                                        | Target  |
|-----------------------------|-------------------------------------------------------------------|---------|
| Conversion Rate             | Conversions / Sessions                                            | > 3%    |
| CAC                         | Total spend / Number of new customers                             | < 50 €  |
| CPL                         | Total spend / Leads                                               | < 15 €  |
| ROAS                        | Revenue / Spend                                                   | > 4×    |
| ROI                         | (Revenue − Cost) / Cost                                           | > 200%  |
| Funnel Drop-off (per step)  | 1 − (StepN / StepN-1)                                             | < 30%   |
| AOV                         | Revenue / Orders                                                  | > 60 €  |
| CLV                         | AOV × Purchase frequency × Avg lifespan                           | > 250 € |
