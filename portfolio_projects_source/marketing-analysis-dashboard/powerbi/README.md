# Power BI File

> ⚠️ The actual `dashboard_template.pbix` is a binary file authored in **Power BI Desktop**.
> It is **not** included as a placeholder in this repo to avoid distributing an empty/unusable file.
>
> **How to recreate the .pbix:**
> 1. Open Power BI Desktop
> 2. Get Data → Folder → select `data/clean/`
> 3. Build the data model exactly as documented in [`../README.md`](../README.md#-data-model)
> 4. Paste the DAX measures from [`measures.dax`](measures.dax) into a new measure table
> 5. Build the 6 report pages described in the README
> 6. Save as `dashboard_template.pbix` in this folder
